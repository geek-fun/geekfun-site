# SqlKit v1.0.4 released

If you use UberLLM, look for MartLLM in AI settings. The preset has a new API address, and existing UberLLM configurations still work. You can also select the new cheapaimodel preset.

The tray menu shows whether the MCP Bridge is running and which port it uses. You can copy the bridge URL from the same menu. If a subscription issue stops the bridge, **Unlock MCP Bridge** opens the upgrade dialog.

The **MCP** tab in Settings has controls to restart the bridge or change its port and auto-start setting. It shows active server sessions and explains any subscription issue that stopped the bridge. Setup instructions for Claude Code, Codex, Cursor, and other AI clients are in the same tab.

SqlKit refreshes your avatar link before it expires. If the refresh fails, you stay signed in and see the default avatar.

Settings now put labels on the left and controls on the right, with monochrome icons for AI providers.
