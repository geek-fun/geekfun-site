# DocKit v2.0.4 released

The tray menu now shows whether the MCP Bridge is running and which port it uses. If a subscription issue stops the bridge, select **Unlock MCP Bridge** in the tray to open the upgrade dialog.

To restart the bridge or change its port or auto-start setting, open the **MCP** tab in Settings. If a subscription issue stops the bridge, you’ll see the details there. The tab also lists active server sessions and has setup instructions you can copy for Claude Code, Codex, Cursor, and other AI clients.

DocKit refreshes the link to your account avatar before it expires.

Settings now put labels on the left and controls on the right. Provider icons are monochrome, and **Auto-compact context** is a switch. In Basic settings, **Plan & Version** is just below **Language**.
