# DocKit v2.0.4 发布

打开系统托盘菜单，就能看到 MCP 桥接是否正在运行，以及它使用的端口。桥接因订阅问题停止时，点「解锁 MCP 桥接」可打开升级窗口。

要重启桥接、更改端口或调整自动启动选项，请打开设置中的「MCP」页。如果桥接因订阅问题停止，这里会说明原因。你也可以在这里查看当前的服务器会话，或复制 Claude Code、Codex、Cursor 等 AI 客户端的配置说明。

DocKit 会提前刷新头像链接，避免头像因链接过期而消失。

设置页现在把标签放在左侧，控件放在右侧。AI 提供商的图标改用单色，「自动压缩上下文」改成了开关。「订阅与版本」现在位于「语言」下方。

[下载适用于 macOS、Windows 或 Linux 的 DocKit](/zh/download#dockit)，或在 [GitHub 查看完整更新说明](https://github.com/geek-fun/dockit/releases/tag/v2.0.4)。
