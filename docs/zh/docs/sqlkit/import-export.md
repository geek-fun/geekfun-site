# 批量导入与导出（传输）

SqlKit 按使用场景提供两套数据导入导出入口：

- **网格快速导出** <DocsBadge variant="community">社区版 · 免费</DocsBadge>：在查询结果面板中将当前结果导出或复制为 **CSV**、**JSON** 或 **SQL `INSERT`**，或在表浏览器中将当前页导出为 **CSV**。详见[导出查询结果](/zh/docs/sqlkit/query-editor#browse-and-export-data)。
- **传输工作区（Transfer）** <DocsBadge variant="ultimate">旗舰版</DocsBadge>：完整的 4 步**批量导出**与**批量导入**向导，支持 **CSV**、**JSONL**、**SQL** 和 **Excel（`.xlsx`）**，内置格式自动识别、字段映射、冲突处理策略、**Dry Run** 演练与后台任务管理。

## 支持的文件格式与参数

| 格式 | 导出可配置项 | 导入能力 |
| --- | --- | --- |
| **CSV**（`.csv`） | 自定义分隔符、引号字符、文件编码、表头开关、全部加引号、`LF` / `CRLF` 换行符 | 自动识别文件格式、分隔符、编码、表头行与列名 |
| **JSONL**（`.jsonl`） | 每行一条 JSON 对象、可配置日期格式（如 ISO-8601） | 自动解析 JSON 键并预览记录 |
| **SQL**（`.sql`） | 目标表名、批量写入条数（默认 `1,000`）、包含 `CREATE TABLE`、包含 `DROP TABLE`、目标方言 | 在选定目标连接与数据库下直接执行 SQL 脚本 |
| **Excel**（`.xlsx`） | 工作表名称、包含表头、自动列宽（Auto-fit）、冻结首行表头 | 读取工作表内容并自动生成列预览与映射 |

*（暂不支持 Parquet 文件导入导出。）*

## 批量导出数据库数据

从主侧边栏进入**传输 → 导出**（或在**查询**对象树中右键某张表选择**导出数据**自动预选该表）：

<DocsSteps>

### 选择导出范围与数据源

选定已保存连接并确定导出粒度：
- **表（Tables）**：勾选一张或多张表，并可按表进一步挑选需要导出的列。
- **数据库（Database）**：导出所选数据库/模式下的全部表。
- **服务器（Server）**：跨当前连接可见的多个数据库批量导出。

### 选择目标格式与选项

在 **CSV**、**JSONL**、**SQL**、**Excel（`.xlsx`）** 中选择输出格式，并微调分隔符、换行符、工作表参数，或 SQL 建表/删表语句与批量大小。

### 实时预览导出结果

在**预览**步骤检查字段标题、转义引号与目标 SQL 方言，确认格式无误后再落盘。

### 选择输出路径并启动任务

指定导出路径后点击**开始导出**，实时进度会同步显示在向导页与**后台任务管理器**中。

</DocsSteps>

## 批量导入文件到数据库

打开**传输 → 导入**将本地 CSV、JSONL、Excel（`.xlsx`）或 SQL 文件写入目标表：

<DocsSteps>

### 拖拽或选择源文件

将文件拖入上传区或从磁盘选取。SqlKit 会自动检测**文件格式、分隔符、文本编码、是否含表头以及全部列名**，并展示前若干行预览。

### 配置目标表与字段映射

在**目标与映射**步骤选择目标**连接**、**数据库**、**模式**（如适用）与**目标表**（或选择自动新建表），逐列核对源列到目标列和类型的映射，或跳过不需要的列。

### 设置冲突策略并运行 Dry Run

在真正写入数据库前，按业务需要调整导入选项：

| 选项 | 行为说明 |
| --- | --- |
| **冲突策略 — `Skip`（跳过）** | 遇到主键或唯一约束冲突时跳过该行并继续导入 |
| **冲突策略 — `Replace`（替换）** | 用新数据替换已有冲突行 |
| **冲突策略 — `Upsert`（插入或更新）** | 不存在则插入，命中键冲突则更新已有记录 |
| **冲突策略 — `Abort`（中止）** | 遇到第一条冲突即立即终止导入 |
| **批大小（Batch Size）** | 每批次写入的行数（默认 `5,000`） |
| **不存在时自动建表** | 根据映射后的字段类型自动创建目标表 |
| **导入前清空表（Truncate）** | 写入前先清空目标表数据（生产环境请慎用） |
| **Dry Run（演练模式）** | 完整校验文件解析、类型转换与列映射，但**不向目标表写入任何数据** |

### 启动导入并核对行级报告

点击**开始导入**，实时查看已处理行数、成功写入数、跳过数与行级错误明细。

</DocsSteps>

::: warning 断点重试注意事项
如果大文件导入在中途因错误中止，前面已经提交的批次可能已写入目标表。重新执行前请先检查目标表当前数据，或将冲突策略调整为 **Skip** / **Upsert** 以免产生重复行。导入 `.sql` 文件前请先审阅脚本内容，所有语句将以当前数据库账号权限直接执行。
:::

## 后台任务管理器

耗时较长的导入导出任务会在后台异步运行，不阻塞你继续使用**查询**或 **Data Studio**。随时打开**任务侧边栏 / 任务管理面板**即可查看：

- 进行中、已完成与失败的历史传输任务
- 已处理行数、跳过数与错误统计
- 任务耗时

::: info 适用边界
传输工作区面向日常开发数据准备、报表提取与常规表级数据交换。针对数十 GB 以上的生产级整库备份和灾难恢复，请仍使用数据库原生备份工具（`pg_dump`、`mysqldump`、`sqlcmd`、Oracle Data Pump / RMAN）。
:::
