# 导入与导出数据库文件

在 SqlKit 旗舰版中，可以用**传输**工作区导入或导出 CSV、JSONL、SQL 和 Excel（`.xlsx`）文件。查询结束后，也可以直接[导出查询返回的行](/zh/docs/sqlkit/query-editor#browse-and-export-data)为 CSV 或 JSON。

## 将 CSV 导入现有表

1. 打开**传输 → 导入**，选择 CSV 文件。检查识别到的列和数据预览。如果表头或分隔符有误，请先核对源文件。
2. 在**目标与映射**中选择连接、数据库、适用的模式和目标表。将源列匹配到目标列。可先使用 **Auto-Map** 按名称匹配，然后逐项核对。
3. 核对导入选项后开始导入。结束后，查看处理了多少行，有没有报错。如果部分数据可能已经写入，重试前先检查目标表。

导入 SQL 文件前请先阅读脚本。脚本会在所选目标上执行，使用目标数据库的 SQL 方言和当前账号的权限。

## 将表数据导出为文件

1. 打开**传输 → 导出**，选择连接、导出范围及所需的表或数据库。
2. 按用途选择格式。CSV 适用于平面表格，JSONL 每行存放一个对象，Excel 适用于电子表格，SQL 可生成脚本。导出 SQL 时，请检查是否包含建表和删表语句。
3. 选择输出路径，点击**开始导出**。检查任务结果并打开文件，确认内容符合预期。
