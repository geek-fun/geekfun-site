# 使用 SqlKit SQL 编辑器

[连接数据库](/zh/docs/sqlkit/connect-to-database)后，打开**查询**。你可以在侧栏切换连接、数据库以及数据库模式。双击对象树中的表，即可在独立标签页中浏览表数据。

## 执行第一条查询 {#run-your-first-query}

1. 选择**新建查询**，在编辑器工具栏确认目标连接和数据库。
2. 输入一条只读测试语句。

   ```sql
   SELECT 1 AS connection_check;
   ```

   在 Oracle 中使用 `SELECT 1 AS connection_check FROM dual;`。

3. 点击**执行**运行编辑器中的全部 SQL。要运行选中的 SQL，先选中文本，再按 macOS 上的 `⌘ + Enter` 或 Windows、Linux 上的 `Ctrl + Enter`。未选中文本时，该快捷键运行光标所在的语句。
4. 在结果面板中确认返回值为 `1`。

## 浏览与导出数据 {#browse-and-export-data}

- 双击侧栏中的表可以浏览数据，也可以从表的菜单选择**查看结构**。
- 使用结果面板的导出按钮将返回的行保存为 CSV 或 JSON。查询中的 `LIMIT`、`TOP` 等行数限制也适用于导出。
- 过滤、编辑行以及查看列和索引的操作见[表格浏览器指南](/zh/docs/sqlkit/table-browser)。要直接导出选定的表，可使用[传输工作区](/zh/docs/sqlkit/import-export)。

## 保存 SQL 和查看执行计划

- 按 `⌘ + S` 或 `Ctrl + S` 将 SQL 保存为 `.sql` 文件。可从侧栏的**已保存的查询**再次打开文件。
- 使用**格式化 SQL**整理编辑器内容，也可以查阅[快捷键](/zh/docs/sqlkit/keyboard-shortcuts)了解格式化、注释和自动补全的操作方式。
- 对支持执行计划的数据库，可使用**解释**查看计划。在支持的数据库中，**分析**会实际执行查询以收集耗时等信息。探索执行计划时，请先使用只读语句。

## 查找并复用历史查询

打开**历史记录**，按 SQL 内容、连接或数据库搜索。可按成功或错误筛选记录，也可以收藏经常使用的查询。选择**清除非收藏**会保留已收藏的记录。

选择重新执行后，历史语句会打开在编辑器里。点**执行**前，先核对标签页上的连接和数据库。如果已删除原连接，尤其要确认当前连的是哪个库。
