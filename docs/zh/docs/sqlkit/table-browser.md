# 数据表格与行编辑

在**查询**侧边栏的对象树中双击任意表，即可在独立标签页中打开它。每个表标签页底部提供五个视图——**Data（数据）**、**Schema（结构）**、**Indexes（索引）**、**Foreign Keys（外键）** 与 **Triggers（触发器）**，并显示各自数量统计。

## 虚拟滚动与网格布局

数据网格基于 `@tanstack/vue-virtual` 实现，仅渲染视口内的可见行，大结果集依然流畅：

- **吸顶横向表头**：横向滚动宽表时表头始终对齐。
- **拖拽列宽**：拖动任意列边框调整宽度。
- **列显隐选择器**：在不修改表结构的前提下临时隐藏或显示指定列。
- **服务端分页**（表数据视图）：自定义每页条数，并展示总行数徽标。

## 搜索、筛选与排序

根据你位于**表数据标签页**还是**查询结果标签页**，SqlKit 提供三种互补的数据过滤方式：

| 方式 | 适用位置 | 工作机制 |
| --- | --- | --- |
| **全表关键词搜索** | 表数据标签页 | 防抖实时搜索，由后端拼装跨列匹配条件并在数据库侧执行。 |
| **SQL `WHERE` 过滤框** | 表数据标签页 | 直接输入省略 `WHERE` 的条件（例如 `status = 'active' AND amount > 100`），按 <kbd>Enter</kbd> 或点击**应用过滤**，可与关键词搜索叠加生效。 |
| **后端列筛选标签** | 查询结果网格 | 从列头菜单或右键单元格选择**按此值筛选** / **排除此值**，支持 `=`、`≠`、`LIKE`、`≥`、`≤`、`BETWEEN`；生效中的条件以彩色标签展示，可一键移除。 |
| **多列排序** | 表视图 & 查询结果 | 点击列头排序，按住 <kbd>Shift</kbd> 点击可叠加次级排序列；`JSON`、数组与 `BLOB` 等复杂列会自动标记为不可排序以避免报错。 |

::: info 当前页排序与全表 `ORDER BY`
在分页视图中点击列头仅对当前加载页重排；若要对百万级全量记录保证严格顺序，请在 [SQL 编辑器](/zh/docs/sqlkit/query-editor)中编写 `ORDER BY`。对于 **Cassandra 与 ScyllaDB（CQL）**，表视图以只读预览形式呈现，不提供网格侧过滤、排序与分页，请在编辑器中编写 CQL 查询。
:::

## 查看复杂字段与 JSON

- **行详情弹窗（Row Details）**：以垂直表单逐列检视整行数据，清晰标注字段类型、`(NULL)` 徽标与美化后的 JSON 文本。
- **JSON 查看器（JSON Viewer）**：针对 JSON 单元格提供格式化高亮预览与一键复制。

## 编辑、复制与删除数据行

SqlKit 同时支持在**表数据标签页**和**单表 `SELECT` 查询结果**中安全修改行数据（后端会自动分析 `SELECT` 语句的目标表与主键信息）：

### 编辑单行

1. 在目标行的**操作**列（或右键菜单）点击**编辑行**。
2. 核对弹窗中受保护的主键字段，修改需要更新的列。
3. 对可为空字段使用独立的**设为 NULL** 勾选框，精准区分 SQL `NULL` 与空字符串 `""`。
4. 点击**保存**。数值和布尔类型会在提交前自动校验；存在未保存修改时关闭弹窗会弹出二次确认。

### 复制行与批量删除

- **复制行（Duplicate Row）**：用当前行的值预填新建表单，修改主键或唯一键即可快速插入相似记录。
- **删除单行**：经破坏性二次确认后删除指定记录。
- **批量删除**：勾选多行后底部出现**批量操作栏（Batch Action Bar）**，经确认后一次性删除选中行。

::: warning 即时执行与无主键表注意事项
- 点击**保存**或确认删除后会**立即向数据库提交**，目前不提供“本地暂存多行修改后预览统一提交”的队列模式。
- 表存在主键时，SqlKit 严格使用主键定位该行；对**没有主键的表**，保存或删除前请务必核对原始列值能够唯一锁定目标行，避免误伤多行。
- 当前数据库登录账号必须具备对应表的 `INSERT`、`UPDATE` 或 `DELETE` 权限。
:::

## 复制与快速导出

右键任意单元格、使用选中行后的**批量操作栏**，或点击网格工具栏即可免费复制和导出（**社区版**包含）：

| 操作 | 支持格式 | 导出范围 |
| --- | --- | --- |
| **复制单元格值** | 纯文本 | 当前聚焦的单个单元格 |
| **复制到剪贴板** | **CSV**、**JSON**、**SQL `INSERT`** | 单行、勾选的多行或当前结果 |
| **导出到本地文件** | **CSV**、**JSON**、**SQL**（查询网格）· **CSV**（表当前页） | 选中行或当前可见页/结果集 |

需要整表/整库导出、生成 Excel（`.xlsx`）或 JSONL，或将文件导入数据库？请前往[批量导入与导出（传输）](/zh/docs/sqlkit/import-export) <DocsBadge variant="ultimate">旗舰版</DocsBadge>。
