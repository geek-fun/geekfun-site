# 数据表格与行编辑

在**查询**侧栏的对象树中双击任意表，即可在独立标签页中打开。每个表标签页底部有五个视图：**Data（数据）**、**Schema（结构）**、**Indexes（索引）**、**Foreign Keys（外键）** 和 **Triggers（触发器）**，并显示各自的数量。

## 虚拟滚动与网格布局

数据网格基于 `@tanstack/vue-virtual` 渲染，只绘制当前视口内的可见行。横向滚动宽表时表头保持固定，拖动列边框可调整列宽，列选择器可临时隐藏或显示指定列（不改表结构），表数据视图支持服务端分页、自定义每页条数与总行数显示。

## 搜索、筛选与排序

| 方式 | 适用位置 | 工作方式 |
| --- | --- | --- |
| 全表关键词搜索 | 表数据标签页 | 防抖实时搜索，由后端拼装跨列条件并在数据库侧执行。 |
| SQL `WHERE` 过滤框 | 表数据标签页 | 输入省略 `WHERE` 的条件（如 `status = 'active' AND amount > 100`），按 <kbd>Enter</kbd> 或点击**应用过滤**，可与关键词搜索叠加。 |
| 后端列筛选标签 | 查询结果网格 | 从列头菜单或右键单元格选择**按此值筛选** / **排除此值**，支持 `=`、`≠`、`LIKE`、`≥`、`≤`、`BETWEEN`；生效中的条件显示为可移除的标签。 |
| 多列排序 | 表视图 & 查询结果 | 点击列头排序，按住 <kbd>Shift</kbd> 点击可叠加次级排序列；`JSON`、数组与 `BLOB` 等复杂列标记为不可排序。 |

::: info 当前页排序与全表 `ORDER BY`
在分页视图中点击列头只对当前加载页重排；如需对整表数据严格排序，请在 [SQL 编辑器](/zh/docs/sqlkit/query-editor)中编写 `ORDER BY`。Cassandra 和 ScyllaDB（CQL）的表视图只提供只读预览，不支持网格侧过滤、排序或分页，请在编辑器中直接执行 CQL。
:::

## 查看复杂字段与 JSON

打开任意行的**行详情（Row Details）**弹窗，可以以垂直表单逐列查看字段类型、`(NULL)` 标记和格式化后的 JSON。对 JSON 单元格打开 **JSON 查看器**可查看缩进高亮内容并一键复制。

## 编辑、复制与删除数据行

在**表数据标签页**以及经可编辑性分析识别出目标表和主键的**单表 `SELECT` 查询结果**中，都可以直接修改行数据。

### 编辑单行

1. 在目标行的**操作**列（或右键菜单）点击**编辑行**。
2. 核对弹窗中受保护的主键字段，修改需要更新的列。
3. 对可为空字段使用独立的**设为 NULL** 勾选框，区分 SQL `NULL` 与空字符串 `""`。
4. 点击**保存**。数值和布尔类型会在提交前做校验；存在未保存修改时关闭弹窗会弹出确认提示。

### 复制行与批量删除

点击**复制行（Duplicate Row）**会用当前行的值预填新建弹窗，修改主键或唯一键后即可保存为新记录。点击**删除行**会在二次确认后删除单条记录；勾选多行后底部出现**批量操作栏（Batch Action Bar）**，经确认后可一次删除全部选中行。

::: warning 即时执行与无主键表注意事项
- 点击**保存**或确认删除后会立即向数据库提交，目前不提供“本地暂存多行修改后预览统一提交”的队列。
- 表有主键时，SqlKit 严格按主键定位该行；对没有主键的表，保存或删除前请确认原始列值能唯一锁定目标行。
- 当前数据库账号必须具备对应表的 `INSERT`、`UPDATE` 或 `DELETE` 权限。
:::

## 复制与快速导出

右键任意单元格、使用选中行后的**批量操作栏**，或点击网格工具栏即可复制和导出（社区版包含）：

| 操作 | 支持格式 | 导出范围 |
| --- | --- | --- |
| 复制单元格值 | 纯文本 | 当前聚焦的单个单元格 |
| 复制到剪贴板 | CSV、JSON、SQL `INSERT` | 单行、勾选的多行或当前结果 |
| 导出到本地文件 | CSV、JSON、SQL（查询网格）；CSV（表当前页） | 选中行或当前可见页/结果集 |

如需整表/整库导出、生成 Excel（`.xlsx`）或 JSONL，或将文件导入数据库，请使用[批量导入与导出（传输）](/zh/docs/sqlkit/import-export) <DocsBadge variant="ultimate">旗舰版</DocsBadge>。
