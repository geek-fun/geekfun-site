# 浏览与编辑表数据

在**查询**中选择目标数据库和模式，双击表后进入 **Data** 标签页。**Schema** 用于查看列类型和主键。**Indexes**、**Foreign Keys** 和 **Triggers** 标签页显示数据库提供的对应元数据。

## 在表中查找数据

- 在搜索框中输入关键词，在表的各列中查找匹配项。
- 在筛选框中输入 `status = 'active'` 这样的 SQL 条件，省略 `WHERE` 关键字。按 Enter 或点击**应用过滤**。支持时可以同时使用关键词搜索和 SQL 筛选。
- 点击可排序的列名，只会调整当前已加载页的行顺序。要对符合条件的全部数据排序，请在 [SQL 查询](/zh/docs/sqlkit/query-editor)中使用 `ORDER BY`。
- 在列选择器中显示或隐藏列。这只影响表格显示。

## 编辑一行

在这一行的**操作**列选**编辑行**。先核对行数据和主键，再修改字段并点**保存**。你的账号需要有更新权限，要改的列也必须允许修改。有主键时，SqlKit 会使用主键定位该行。对于没有主键的表，保存前请确认原始列值可以唯一标识目标行。

## 导出当前页

表格工具栏的 CSV 导出会按当前顺序保存这一页的数据，并使用当前显示的列。需要用 SQL 指定导出范围时，可[导出查询结果](/zh/docs/sqlkit/query-editor#browse-and-export-data)。需要将选定的整表导出为文件时，请使用[传输工作区](/zh/docs/sqlkit/import-export)。
