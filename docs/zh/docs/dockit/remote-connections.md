# SSH 隧道和系统代理

DocKit 旗舰版可以通过堡垒机或系统代理连接数据库。使用堡垒机时，在 SSH 档案里填堡垒机地址和登录信息，在连接表单里填数据库的地址和登录信息。

## 添加可复用的 SSH 配置档案

1. [创建或编辑连接](/zh/docs/dockit/connect-to-server)，在数据库表单中填写最后一跳 SSH 主机可以访问的数据库地址。
2. 打开**高级设置**中的 **SSH 隧道**，添加现有档案或新建档案。填写 SSH 主机、端口和用户名，选择密码、私钥或 SSH Agent 认证。
3. 使用多个堡垒机时，请按照连接顺序添加档案，也可以拖动调整顺序。最后一跳负责连接数据库。从当前链路移除档案后，仍可在其他连接中使用该档案。
4. 即使 SSH 档案已通过测试，保存前也要在连接对话框中点**测试连接**，检查整条链路以及数据库能否登录。

## 添加系统代理

如果 SSH 区域显示检测到的系统代理，可以点击**添加**将其用于当前连接。系统代理会排列在所有 SSH 档案之前。如果组织要求直接访问服务器或堡垒机，请从该连接移除系统代理。

## 排查连接失败

- 如果提示跳过隧道，请检查登录状态和旗舰版权限。社区版或未登录会话会尝试直连，同时保留已保存的档案设置。
- 如果 SSH 档案测试成功而数据库测试失败，请确认最后一跳可以解析和访问数据库地址，再检查数据库凭据及 TLS 设置。
- MongoDB 通过 SSH 使用 **URI 认证**时，需要单主机的 `mongodb://` URI。如果需要多主机 URI 或 `mongodb+srv://` URI，请使用直连。
