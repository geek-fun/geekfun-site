# 配置 AI 权限

Agentic Data Studio、侧边栏助手和外部 MCP 客户端共用连接的 AI 权限。手动在编辑器中操作时，仍以数据库账号和应用功能权限为准。修改 AI 默认权限和单个连接的权限需要旗舰版。

## 设置实际访问权限

1. 在**设置 → MCP 桥接 → 默认 AI 权限**中设置连接会继承哪些权限。全新安装时，DocKit 允许读取、新增和更新数据，禁止删除和管理操作。如果是从旧版升级的，请检查现有连接的设置，DocKit 会保留原有的限制。
2. 如果要更改单个连接，请编辑连接并在**高级设置**中展开 **AI 权限**。选择**自定义**可分别设定读取、新增、更新、删除和管理权限。如果将某项操作设为继承，它会使用当前的系统默认值。
3. 在 Data Studio 中仅挂载本次需要的连接。会话可以进一步限制权限。侧边栏助手使用当前连接的权限。

| 访问级别 | 可执行的操作 |
| --- | --- |
| **禁止访问** | 禁止 AI 访问数据或执行管理操作。 |
| **读取** | 读取数据和查看结构。 |
| **读取与修改数据** | 读取、新增、更新和删除数据。 |
| **完全访问** | 数据操作、结构变更和管理操作。 |
| **自定义** | 按操作分别设置。 |

## 确认已获授权的操作

**询问**和**自动**模式决定何时需要确认，权限仍由连接和会话设置决定。询问模式会在写入等高风险操作前询问。自动模式可直接执行已获授权的高风险操作。破坏性操作在两种模式下都需要确认，除非已有匹配的**始终允许**规则。首次执行或重试时，DocKit 都会检查当前设置，数据库也会检查账号是否有权执行该操作。

通过外部 MCP 客户端操作时，确认提示由客户端控制。DocKit 会提供风险标注，并在执行前检查自己的权限设置。请查看客户端的审批设置。

## 处理被阻止的请求

在被阻止的消息中打开**检查权限**，查看是哪个连接的哪项操作被拒绝。如需变更权限，保存后回到对话并选择**重试请求**。重试会按当前权限和确认规则重新检查。
