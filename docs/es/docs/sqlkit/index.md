# Primeros pasos con SqlKit

SqlKit es un cliente SQL de escritorio para macOS, Windows y Linux. Puedes explorar las tablas de MySQL, PostgreSQL, SQL Server y Oracle, o abrir un archivo SQLite local.

1. [Instala SqlKit](/es/docs/sqlkit/installation).
2. [Añade y prueba una conexión](/es/docs/sqlkit/connect-to-database).
3. [Ejecuta una consulta de solo lectura](/es/docs/sqlkit/query-editor) y revisa el resultado.
4. Consulta los [atajos del editor](/es/docs/sqlkit/keyboard-shortcuts) para ejecutar y guardar SQL.

## Guías por base de datos

[MySQL](/es/docs/sqlkit/mysql-gui-client), [PostgreSQL](/es/docs/sqlkit/postgresql-gui-client), [SQL Server](/es/docs/sqlkit/sql-server-gui-client), [Oracle Database](/es/docs/sqlkit/oracle-gui-client) y [SQLite](/es/docs/sqlkit/sqlite-gui-client).

Para otros motores, consulta la [lista de bases de datos y controladores (en inglés)](/docs/sqlkit/supported-databases).
