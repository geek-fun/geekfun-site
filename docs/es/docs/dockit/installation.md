# Instalar DocKit en macOS, Windows y Linux

En la [página de descargas de DocKit](/es/download#dockit), elige el paquete de tu sistema. Los instaladores para Mac son universales (Apple Silicon e Intel). Los de Windows y Linux son para x64.

## macOS

Abre el archivo `.dmg` y arrastra DocKit a **Aplicaciones**. Luego ábrelo desde esa carpeta.

## Windows

Ejecuta el instalador `.exe` o `.msi` y sigue los pasos que aparecen en pantalla. Al terminar, abre DocKit desde el menú Inicio.

## Linux

- Debian y Ubuntu usan el paquete `.deb`. Desde la carpeta de descargas, ejecuta `sudo apt install ./paquete.deb` con el nombre real del archivo.
- Para Fedora, usa el paquete `.rpm` con `sudo dnf install ./paquete.rpm`.
- Para AppImage, da permiso de ejecución al archivo con `chmod +x ./archivo.AppImage` y ábrelo. Sustituye `archivo.AppImage` por el nombre descargado.

## Primera apertura

[Configura tu primera conexión](/es/docs/dockit/connect-to-server) con el botón **+**. Al cerrar la ventana, DocKit sigue en segundo plano, incluidas las transferencias activas. Sal de la aplicación desde la bandeja si quieres detenerla.
