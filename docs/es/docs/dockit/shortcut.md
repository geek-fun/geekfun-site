# Atajos de teclado de DocKit

Haz clic dentro del editor antes de usar un atajo.

| Acción | macOS | Windows y Linux |
| --- | --- | --- |
| Ejecutar la selección o la consulta actual | `⌘ + Enter` | `Ctrl + Enter` |
| Guardar en un archivo | `⌘ + S` | `Ctrl + S` |
| Comentar o descomentar una línea | `⌘ + /` | `Ctrl + /` |
| Mostrar sugerencias | `⌘ + Space` | `Ctrl + Space` |
| Dar formato | `⌘ + I` | `Ctrl + I` |
| Plegar o desplegar el bloque actual | `⌘ + Option + L` | `Ctrl + Shift + L` |
| Ir a la petición anterior | `⌘ + ↑` | `Ctrl + ↑` |
| Ir a la petición siguiente | `⌘ + ↓` | `Ctrl + ↓` |

Los atajos con flechas y el plegado de peticiones se refieren al editor de Elasticsearch, OpenSearch y EasySearch. Cuando tengas varias peticiones, coloca el cursor dentro de la que quieres ejecutar.

Si `⌘ + Space` abre Spotlight, cambia el atajo de Spotlight en los ajustes de teclado de macOS.
