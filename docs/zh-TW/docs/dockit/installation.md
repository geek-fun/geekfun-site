# 在 macOS、Windows 或 Linux 安裝 DocKit

在 [DocKit 下載頁面（英文）](/download#dockit) 選擇安裝檔。macOS 安裝檔支援 Apple Silicon 和 Intel，Windows 和 Linux 套件為 x64 版本。

## macOS

開啟 `.dmg` 檔案，把 DocKit 拖到「應用程式」資料夾。複製完成後，從該資料夾啟動應用程式。

## Windows

執行 `.exe` 或 `.msi` 安裝檔，依畫面指示完成安裝，再從「開始」功能表開啟 DocKit。

## Linux

- Debian 和 Ubuntu 使用 `.deb` 套件。在下載目錄執行 `sudo apt install ./package.deb`。
- Fedora 使用 `.rpm` 套件。執行 `sudo dnf install ./package.rpm`。
- 使用 AppImage 時，先執行 `chmod +x ./app.AppImage` 賦予執行權限，再開啟檔案。

請把指令中的檔名換成實際下載的檔名。

## 第一次啟動

按 **+** [新增第一個連線](/zh-TW/docs/dockit/connect-to-server)。關閉視窗後，DocKit 和進行中的傳輸仍會在背景執行。若要結束程式，請使用選單列或系統匣的選單。
