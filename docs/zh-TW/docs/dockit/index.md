# 開始使用 DocKit

DocKit 是 NoSQL 桌面用戶端。每種資料庫有自己的連線欄位和查詢編輯器。

1. [安裝 DocKit](/zh-TW/docs/dockit/installation)。
2. [新增並測試資料庫連線](/zh-TW/docs/dockit/connect-to-server)。
3. 如果使用 Elasticsearch、OpenSearch 或 EasySearch，可[執行搜尋查詢](/zh-TW/docs/dockit/search-editor)，並參考[編輯器快速鍵](/zh-TW/docs/dockit/shortcut)。

如果使用 MongoDB 或 DynamoDB，請參考[查詢 MongoDB 文件](./mongodb-workspace)或[用 PartiQL 查詢 DynamoDB](./dynamodb-query-editor)的步驟。
