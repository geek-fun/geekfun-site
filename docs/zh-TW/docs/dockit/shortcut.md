# DocKit 鍵盤快速鍵

使用快速鍵前，先點一下編輯器。

| 操作 | macOS | Windows 與 Linux |
| --- | --- | --- |
| 執行選取的內容或目前查詢 | `⌘ + Enter` | `Ctrl + Enter` |
| 儲存成檔案 | `⌘ + S` | `Ctrl + S` |
| 切換單行註解 | `⌘ + /` | `Ctrl + /` |
| 顯示自動完成建議 | `⌘ + Space` | `Ctrl + Space` |
| 格式化 | `⌘ + I` | `Ctrl + I` |
| 收合或展開目前區塊 | `⌘ + Option + L` | `Ctrl + Shift + L` |
| 移到上一個請求 | `⌘ + ↑` | `Ctrl + ↑` |
| 移到下一個請求 | `⌘ + ↓` | `Ctrl + ↓` |

移動和收合請求的快速鍵適用於 Elasticsearch、OpenSearch 和 EasySearch 編輯器。編輯器裡有多個請求時，先將游標放在要執行的請求內。

若 `⌘ + Space` 開啟 Spotlight，可到 macOS 的鍵盤設定中調整 Spotlight 快速鍵。
