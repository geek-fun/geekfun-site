# SqlKit 鍵盤快速鍵

使用快速鍵前，先點一下編輯器。

| 操作 | macOS | Windows 與 Linux |
| --- | --- | --- |
| 執行選取的內容或目前查詢 | `⌘ + Enter` | `Ctrl + Enter` |
| 儲存成檔案 | `⌘ + S` | `Ctrl + S` |
| 切換單行註解 | `⌘ + /` | `Ctrl + /` |
| 顯示自動完成建議 | `⌘ + Space` | `Ctrl + Space` |
| 格式化 | `Option + Shift + F` | `Alt + Shift + F` |
| 查看查詢計畫（支援時） | `F6` | `F6` |

有選取 SQL 時，執行快速鍵只執行選取範圍。沒有選取時則執行游標所在的陳述式。若要執行整份內容，請按工具列的 **執行**。

若 `⌘ + Space` 開啟 Spotlight，可到 macOS 的鍵盤設定中調整 Spotlight 快速鍵。
