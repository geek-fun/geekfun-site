# 開始使用 SqlKit

SqlKit 是適用於 macOS、Windows 與 Linux 的 SQL 桌面用戶端。你可以連線到 MySQL、PostgreSQL、SQL Server、Oracle 等伺服器，也可以開啟本機 SQLite 檔案。

先[安裝 SqlKit](/zh-TW/docs/sqlkit/installation)，再[新增資料庫連線](/zh-TW/docs/sqlkit/connect-to-database)。用[唯讀查詢](/zh-TW/docs/sqlkit/query-editor)確認連線正常。日常操作可查閱[鍵盤快速鍵](/zh-TW/docs/sqlkit/keyboard-shortcuts)。

## 資料庫指南

[MySQL](/zh-TW/docs/sqlkit/mysql-gui-client)、[PostgreSQL](/zh-TW/docs/sqlkit/postgresql-gui-client)、[SQL Server](/zh-TW/docs/sqlkit/sql-server-gui-client)、[Oracle Database](/zh-TW/docs/sqlkit/oracle-gui-client)、[SQLite](/zh-TW/docs/sqlkit/sqlite-gui-client)。

其他引擎可查閱[支援的資料庫與驅動程式（英文）](/docs/sqlkit/supported-databases)。
