# SqlKit keyboard shortcuts

These shortcuts apply in the **Queries** workspace. Click inside the SQL editor before using an editor shortcut.

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Run selected SQL or the statement at the cursor | `⌘ + Enter` | `Ctrl + Enter` |
| Save the query as a `.sql` file or update its saved file | `⌘ + S` | `Ctrl + S` |
| Toggle a line comment | `⌘ + /` | `Ctrl + /` |
| Format SQL | `Option + Shift + F` | `Alt + Shift + F` |
| Show autocomplete suggestions | `⌘ + Space` | `Ctrl + Space` |
| Explain the query, where supported | `F6` | `F6` |
| Close the active workspace tab | `⌘ + W` | `Ctrl + W` |

Highlight the SQL you want to run before pressing `⌘ + Enter` or `Ctrl + Enter`. With no selection, the editor runs the statement at the cursor. Use **Execute** in the toolbar to run the full editor contents.

If `⌘ + Space` opens Spotlight, change the Spotlight binding in macOS Keyboard Shortcuts so you can use that shortcut in SqlKit.

See the [SQL editor guide](/docs/sqlkit/query-editor) for query results, exports, and execution plans.
