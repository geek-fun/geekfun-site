# DocKit 시작하기

DocKit은 데이터베이스 유형에 따라 연결 설정과 쿼리 편집기를 제공하는 데스크톱 NoSQL 클라이언트입니다.

1. [DocKit을 설치합니다](/ko/docs/dockit/installation).
2. [데이터베이스 연결을 등록하고 테스트합니다](/ko/docs/dockit/connect-to-server).
3. Elasticsearch, OpenSearch, EasySearch를 사용한다면 [검색 쿼리를 실행합니다](/ko/docs/dockit/search-editor). [편집기 단축키](/ko/docs/dockit/shortcut)도 확인할 수 있습니다.

다른 편집기는 [DocKit에서 MongoDB 문서 조회하기](./mongodb-workspace) 또는 [DocKit의 PartiQL 편집기에서 DynamoDB 조회하기](./dynamodb-query-editor)를 참조하세요.
