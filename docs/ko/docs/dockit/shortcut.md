# DocKit 키보드 단축키

편집기를 클릭한 다음 단축키를 누릅니다.

| 작업 | macOS | Windows 및 Linux |
| --- | --- | --- |
| 선택 영역 또는 현재 쿼리 실행 | `⌘ + Enter` | `Ctrl + Enter` |
| 파일로 저장 | `⌘ + S` | `Ctrl + S` |
| 줄 주석 켜기 또는 끄기 | `⌘ + /` | `Ctrl + /` |
| 자동 완성 열기 | `⌘ + Space` | `Ctrl + Space` |
| 서식 정리 | `⌘ + I` | `Ctrl + I` |
| 현재 블록 접기 또는 펼치기 | `⌘ + Option + L` | `Ctrl + Shift + L` |
| 이전 요청으로 이동 | `⌘ + ↑` | `Ctrl + ↑` |
| 다음 요청으로 이동 | `⌘ + ↓` | `Ctrl + ↓` |

요청 이동과 접기는 Elasticsearch, OpenSearch, EasySearch 편집기에서 사용할 수 있습니다. 요청이 여러 개일 때는 실행할 요청 안에 커서를 둡니다.

`⌘ + Space`가 Spotlight를 열면 macOS 키보드 설정에서 Spotlight 단축키를 바꿀 수 있습니다.
