# SqlKit 시작하기

SqlKit은 macOS, Windows, Linux에서 실행되는 SQL 클라이언트입니다. MySQL, PostgreSQL, SQL Server, Oracle 서버에 연결하거나 로컬 SQLite 파일을 열 수 있습니다.

[앱을 설치](/ko/docs/sqlkit/installation)하고 [데이터베이스 연결을 추가](/ko/docs/sqlkit/connect-to-database)합니다. [읽기 전용 쿼리](/ko/docs/sqlkit/query-editor)로 접속을 확인한 뒤, 자주 쓰는 작업은 [키보드 단축키](/ko/docs/sqlkit/keyboard-shortcuts)로 실행할 수 있습니다.

## 데이터베이스별 가이드

[MySQL](/ko/docs/sqlkit/mysql-gui-client), [PostgreSQL](/ko/docs/sqlkit/postgresql-gui-client), [SQL Server](/ko/docs/sqlkit/sql-server-gui-client), [Oracle Database](/ko/docs/sqlkit/oracle-gui-client), [SQLite](/ko/docs/sqlkit/sqlite-gui-client).

다른 엔진은 [지원 데이터베이스와 드라이버 목록(영어)](/docs/sqlkit/supported-databases)에서 확인합니다.
