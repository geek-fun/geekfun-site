# SqlKit 키보드 단축키

편집기를 클릭한 다음 단축키를 누릅니다.

| 작업 | macOS | Windows 및 Linux |
| --- | --- | --- |
| 선택 영역 또는 현재 쿼리 실행 | `⌘ + Enter` | `Ctrl + Enter` |
| 파일로 저장 | `⌘ + S` | `Ctrl + S` |
| 줄 주석 켜기 또는 끄기 | `⌘ + /` | `Ctrl + /` |
| 자동 완성 열기 | `⌘ + Space` | `Ctrl + Space` |
| 서식 정리 | `Option + Shift + F` | `Alt + Shift + F` |
| 실행 계획 보기(지원되는 엔진) | `F6` | `F6` |

SQL을 선택하고 실행 단축키를 누르면 선택 영역만 실행됩니다. 선택한 텍스트가 없으면 커서 위치의 문을 실행합니다. 편집기 전체 내용을 실행하려면 도구 모음의 **실행**을 클릭합니다.

`⌘ + Space`가 Spotlight를 열면 macOS 키보드 설정에서 Spotlight 단축키를 바꿀 수 있습니다.
