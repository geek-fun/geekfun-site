# GEEKFUN 소개

GEEKFUN은 개발자용 도구를 만들고 유지보수하는 오픈 소스 스튜디오입니다. DocKit과 SqlKit으로 데이터베이스를 조회하고 관리할 수 있습니다. Data Studio Agent는 MCP를 통해 이 도구들을 AI 코딩 에이전트에 연결합니다.
