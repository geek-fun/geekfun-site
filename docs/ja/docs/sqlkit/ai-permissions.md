# SqlKit の AI アクセス権限を設定する

SqlKit は、アプリ内のアシスタントや外部 MCP クライアントからの要求に接続の AI 権限を適用します。権限を変更するには Ultimate が必要です。

## デフォルトと接続ごとの権限 {#connection-permissions}

**設定 → MCPブリッジ → デフォルトの AI 権限**を開きます。構造の確認と読み取りだけにするには**読み取り**を選び、保存します。

保存済みの接続を編集し、**詳細 → AI 権限**を開きます。デフォルトを引き継ぐか、**カスタム**で操作ごとの許可を設定できます。Data Studio の会話は接続の権限をさらに制限できます。

## 確認、自動、クライアントの承認 {#approvals}

**確認**は許可された書き込みなどの操作で確認を求めます。**自動**では一部の許可済み操作が直接実行されます。破壊的な操作では、保存済みの確認ルールが適用される場合を除き、どちらのモードでも確認します。MCP の承認画面はクライアントが管理し、SqlKit とデータベースの権限は引き続き適用されます。

## 拒否された操作を確認する {#blocked-actions}

Data Studio のメッセージで**権限を確認**し、対象の接続と操作を確認します。必要な権限を保存したうえで**リクエストを再試行**します。AI に使わせない接続は**アクセスなし**に設定します。
