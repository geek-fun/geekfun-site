# SqlKit のキーボードショートカット

エディターにフォーカスを移してから操作します。

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 選択範囲または現在のクエリを実行 | `⌘ + Enter` | `Ctrl + Enter` |
| ファイルに保存 | `⌘ + S` | `Ctrl + S` |
| 行コメントを切り替え | `⌘ + /` | `Ctrl + /` |
| 入力候補を表示 | `⌘ + Space` | `Ctrl + Space` |
| 整形 | `Option + Shift + F` | `Alt + Shift + F` |
| クエリプランを表示（対応する場合） | `F6` | `F6` |

SQL を選択した状態で実行すると、その選択範囲だけが対象になります。未選択の場合はカーソル位置の文を実行します。エディター全体を実行するには、ツールバーの**実行**を使ってください。

macOS で `⌘ + Space` を押すと Spotlight が開く場合は、キーボード設定で Spotlight のショートカットを変更できます。
