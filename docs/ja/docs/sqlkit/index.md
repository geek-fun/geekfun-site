# SqlKit を使い始める

SqlKit は macOS、Windows、Linux 向けの SQL クライアントです。MySQL や PostgreSQL などのサーバーに接続し、ローカルの SQLite ファイルも開けます。

[インストール](/ja/docs/sqlkit/installation)後、[データベースに接続](/ja/docs/sqlkit/connect-to-database)します。[読み取り専用のクエリを実行](/ja/docs/sqlkit/query-editor)し、結果が返ることを確認しましょう。エディターの操作には[キーボードショートカット](/ja/docs/sqlkit/keyboard-shortcuts)を使えます。

## データベース別ガイド

[MySQL](/ja/docs/sqlkit/mysql-gui-client)、[PostgreSQL](/ja/docs/sqlkit/postgresql-gui-client)、[SQL Server](/ja/docs/sqlkit/sql-server-gui-client)、[Oracle Database](/ja/docs/sqlkit/oracle-gui-client)、[SQLite](/ja/docs/sqlkit/sqlite-gui-client)。

ほかのエンジンは[対応データベースとドライバーの一覧（英語）](/docs/sqlkit/supported-databases)を参照してください。
