# DocKit のキーボードショートカット

エディターにフォーカスを移してから操作します。

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 選択範囲または現在のクエリを実行 | `⌘ + Enter` | `Ctrl + Enter` |
| ファイルに保存 | `⌘ + S` | `Ctrl + S` |
| 行コメントを切り替え | `⌘ + /` | `Ctrl + /` |
| 入力候補を表示 | `⌘ + Space` | `Ctrl + Space` |
| 整形 | `⌘ + I` | `Ctrl + I` |
| 現在のブロックを折りたたむ、または展開 | `⌘ + Option + L` | `Ctrl + Shift + L` |
| 前のリクエストへ移動 | `⌘ + ↑` | `Ctrl + ↑` |
| 次のリクエストへ移動 | `⌘ + ↓` | `Ctrl + ↓` |

リクエスト間の移動と折りたたみは Elasticsearch、OpenSearch、EasySearch のエディターで使えます。リクエストが複数ある場合は、実行したいリクエスト内にカーソルを置きます。

macOS で `⌘ + Space` を押すと Spotlight が開く場合は、キーボード設定で Spotlight のショートカットを変更できます。
