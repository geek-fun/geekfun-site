# GEEKFUN について

GEEKFUN は、開発者向けツールを作り、保守するオープンソースのスタジオです。DocKit と SqlKit でデータベースの検索や管理ができ、Data Studio Agent は MCP を使ってこれらのツールをコーディングエージェントにつなぎます。
