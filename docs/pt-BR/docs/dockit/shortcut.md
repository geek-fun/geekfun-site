# Atalhos de teclado do DocKit

Clique no editor antes de usar um atalho.

| Ação | macOS | Windows e Linux |
| --- | --- | --- |
| Executar a seleção ou a consulta atual | `⌘ + Enter` | `Ctrl + Enter` |
| Salvar em arquivo | `⌘ + S` | `Ctrl + S` |
| Comentar ou descomentar a linha | `⌘ + /` | `Ctrl + /` |
| Abrir as sugestões | `⌘ + Space` | `Ctrl + Space` |
| Formatar | `⌘ + I` | `Ctrl + I` |
| Recolher ou expandir o bloco atual | `⌘ + Option + L` | `Ctrl + Shift + L` |
| Ir para a requisição anterior | `⌘ + ↑` | `Ctrl + ↑` |
| Ir para a próxima requisição | `⌘ + ↓` | `Ctrl + ↓` |

Os atalhos com setas e para recolher blocos são do editor de Elasticsearch, OpenSearch e EasySearch. Se houver várias requisições, deixe o cursor na que você quer executar.

Se `⌘ + Space` abrir o Spotlight, altere o atalho do Spotlight nas configurações de teclado do macOS.
