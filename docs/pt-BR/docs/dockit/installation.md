# Instalar o DocKit no macOS, Windows e Linux

Na [página de download](/pt-BR/download#dockit), selecione o pacote do DocKit para o seu sistema. O instalador do Mac funciona em Apple Silicon e Intel. Os pacotes de Windows e Linux são para x64.

## macOS

Abra o arquivo `.dmg`. Arraste o DocKit para **Aplicativos** e abra o programa nessa pasta.

## Windows

Abra o instalador `.exe` ou `.msi` e siga as instruções. Depois, inicie o DocKit pelo menu Iniciar.

## Linux

- No Debian ou Ubuntu, instale o `.deb` usando `sudo apt install ./pacote.deb` na pasta de downloads.
- No Fedora, use o `.rpm` com `sudo dnf install ./pacote.rpm`.
- Se escolher AppImage, dê permissão de execução com `chmod +x ./arquivo.AppImage` e abra o arquivo.

Troque os nomes nos comandos pelos nomes dos arquivos baixados.

## Primeiro acesso

Use **+** para [criar a primeira conexão](/pt-BR/docs/dockit/connect-to-server). Ao fechar a janela, o DocKit continua em segundo plano e mantém as transferências em andamento. Para encerrar o programa, use o menu da bandeja.
