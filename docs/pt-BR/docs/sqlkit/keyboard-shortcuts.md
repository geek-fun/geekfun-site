# Atalhos de teclado do SqlKit

Clique no editor antes de usar um atalho.

| Ação | macOS | Windows e Linux |
| --- | --- | --- |
| Executar a seleção ou a consulta atual | `⌘ + Enter` | `Ctrl + Enter` |
| Salvar em arquivo | `⌘ + S` | `Ctrl + S` |
| Comentar ou descomentar a linha | `⌘ + /` | `Ctrl + /` |
| Abrir as sugestões | `⌘ + Space` | `Ctrl + Space` |
| Formatar | `Option + Shift + F` | `Alt + Shift + F` |
| Ver o plano da consulta (quando disponível) | `F6` | `F6` |

O atalho de execução usa o texto selecionado ou a instrução em que o cursor está. Para rodar todo o conteúdo, clique em **Executar** na barra do editor.

Se `⌘ + Space` abrir o Spotlight, altere o atalho do Spotlight nas configurações de teclado do macOS.
